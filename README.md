## 🧭 About Me

I'm a final-year Computer Science student (CS '26) specializing in **cybersecurity, Linux systems, and GRC-aligned security engineering**. My work sits at the intersection of two things most people treat separately: *building technical security controls* and *understanding the governance frameworks those controls are designed to satisfy*.

Rather than just reading about NIST CSF or ISO 27001, I build the tools that implement what those frameworks require — file integrity monitors, access control scripts, forensic analysis environments — then map the implementation back to control objectives.

**Current focus areas:**
- 🔵 **Blue Team / SOC:** Threat detection, log analysis, incident response tooling, SIEM-adjacent automation
- 📋 **GRC:** Security controls implementation, risk assessment methodology, NIST CSF alignment
- 🔬 **DFIR:** Network forensics, malware artifact analysis, packet-level threat reconstruction
- 🐧 **Linux Security Engineering:** System hardening, daemon development, access control, kernel-level tooling
